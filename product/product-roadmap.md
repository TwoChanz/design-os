# Product Roadmap

## Phase 1 — Chrome Extension MVP

### 1. Page Scoring
The core "Score this page" flow that generates a ClarityScore (0–100) with category breakdown for pricing, trials, cancellation, data practices, and permissions.

### 2. Evidence Prompt
The fallback UI when page signals are insufficient, presenting 3 quick questions to improve score accuracy and confidence.

### 3. Score Reports
Saving score reports locally, viewing score history, and generating shareable score cards.

### 4. Subscription Tracker
Manual subscription management with a running monthly spend total, stored locally.

## Phase 2+ — Future Vision

### 5. Future Enhancements
Reserved for post-MVP features including potential web dashboard, cross-browser support, optional cloud sync, and community-sourced transparency signals. Not part of current development scope.
